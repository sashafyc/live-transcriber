# Live Transcriber

![версия](https://img.shields.io/badge/версия-2.0.0-blue) ![платформа](https://img.shields.io/badge/платформа-macOS%2015%2B-lightgrey)

Приложение в строке меню macOS. Умеет две вещи:

- **Диктовка.** Держите Fn и говорите, отпустили — текст появится там, где курсор.
- **Созвоны.** Пишет созвон вместе со звуком собеседника, расшифровывает его по
  голосам, делает итог и присылает в Telegram.

Работает целиком на вашем маке, без своего сервера. Ключи хранятся в связке
ключей macOS и в репозиторий не попадают.

## Диктовка

- Держите клавишу — пишет микрофон, внизу экрана плашка с волной. Отпустили —
  текст распознаётся и вставляется в любое приложение, где стоит курсор
- Клавиша на выбор: Fn 🌐, правый Option, правый Command или правый Control.
  Нажатие с буквой считается сочетанием клавиш и диктовку не запускает
- Распознавание: OpenAI, AssemblyAI или свой адрес с OpenAI-совместимым API.
  Модель вписывается вручную или выбирается из подсказок
- Оформление текста нейросетью (OpenAI или DeepSeek, по желанию): абзацы,
  пунктуация, без слов-паразитов и оговорок, смысл не меняется. Короткие фразы
  вставляются сразу, без оформления
- История за сутки: текст можно скопировать, если вставка ушла не туда, взять
  исходник до оформления или повторить распознавание без передиктовки

## Созвоны

- Микрофон и звук собеседника пишутся одновременно, двумя дорожками. Выход звука
  не переключается: наушники остаются наушниками, в приложении созвона ничего
  перенастраивать не нужно
- Проверка звука до начала: видно, слышит ли микрофон и доходит ли звук собеседника
- Режим «Внешний созвон» для разговора по телефону: пишется только микрофон,
  говорящие разделяются по голосам
- Расшифровка по ходу записи, кусками по минуте. Ваша речь подписана «Я», речь
  собеседника — «Собеседник», несколько собеседников различаются буквами
- Итог разговора через DeepSeek, задание для итога можно поменять перед каждой записью
- Итог в отдельном окне с кнопкой «Скопировать» и отправка в Telegram-чат или тему группы
- История за 30 дней: итоги и полные расшифровки. Звук записи хранится неделю,
  и рваную расшифровку можно переделать целиком одной кнопкой

## Установка

Нужен мак на Apple Silicon с macOS 15 или новее. Ни ffmpeg, ни BlackHole не нужны.

Скачайте архив из [релизов](https://github.com/sashafyc/live-transcriber/releases),
распакуйте и перетащите `Live Transcriber.app` в «Программы». Приложение подписано
сертификатом разработчика, но не заверено Apple, поэтому при первом запуске macOS
его не откроет. Откройте его через правый клик → «Открыть» или выполните:

```bash
xattr -dr com.apple.quarantine "/Applications/Live Transcriber.app"
```

### Разрешения

| Что | Зачем | Когда спросят |
|---|---|---|
| Микрофон | диктовка и созвоны | при первой записи |
| Универсальный доступ | ловить клавишу диктовки и вставлять текст | при первом запуске |
| Запись экрана и звука системы | звук собеседника на созвоне | при первой записи созвона |
| Уведомления | «запись идёт», «собеседника не слышно» и т. п. | при первом запуске |

Без разрешения на звук системы запись идёт, но дорожка собеседника остаётся
пустой: система отдаёт тишину без всякой ошибки. «Проверить звук» это покажет.

### Сборка из исходников

Нужен Xcode (полный, не только Command Line Tools).

```bash
git clone https://github.com/sashafyc/live-transcriber.git
cd live-transcriber
./build.sh --install
```

Скрипт соберёт приложение, подпишет его сертификатом Apple Development, если он
есть в связке ключей, и положит в «Программы». С подписью разрешения не слетают
при пересборке, без неё (ad-hoc) их придётся выдавать заново после каждой сборки.

## Ключи

Значок в строке меню → «Настройки». Для созвонов там же кнопка «Проверить ключи».

| Что | Где взять | Для чего |
|---|---|---|
| Ключ AssemblyAI | [assemblyai.com](https://www.assemblyai.com) | расшифровка созвонов, по желанию диктовка |
| Ключ OpenAI | [platform.openai.com](https://platform.openai.com) | диктовка и её оформление, по желанию |
| Ключ DeepSeek | [platform.deepseek.com](https://platform.deepseek.com) | итог созвона, по желанию оформление диктовки |
| Токен Telegram-бота | [@BotFather](https://t.me/BotFather) | отправка итога в чат |
| Ссылка на чат | скопировать ссылку на любое сообщение в чате | куда слать итог |

Ссылка на чат понимается в любом виде: `https://t.me/c/1234567890/42`,
`-1001234567890/42`, `-1001234567890` или `@имяканала`. Если в ссылке есть номер
темы, итоги уйдут именно в неё. Бота нужно добавить в чат и дать право писать.

Голоса на одной дорожке разделяет только AssemblyAI, поэтому для созвонов он
стоит по умолчанию. С OpenAI дорожки «Я» и «Собеседник» расшифруются по отдельности.

## Как записать созвон

1. Значок в строке меню → «Начать запись созвона…»
2. Впишите название и при желании поправьте задание для итога
3. Переключатель «Внешний созвон» — для разговора по телефону: звук идёт мимо
   компьютера, пишется только микрофон
4. «Проверить звук» покажет, слышно ли микрофон и идёт ли звук собеседника
5. «Начать запись». Значок в строке меню станет кружком записи, а если микрофон
   замолчит — перечёркнутым микрофоном
6. «Остановить и получить итог»: приложение дорасшифрует хвост, сделает итог,
   покажет его и отправит в Telegram

Когда вы слушаете собеседника через динамики, его голос попадает и в микрофон.
Такие повторы приложение глушит по звуку ещё до расшифровки.

## Где что лежит

```
~/Library/Application Support/Live Transcriber/
├── logs/app.log             общий лог с ротацией
├── dictation.json           история диктовок за сутки
└── records/
    └── 2026-10-28-1610-Созвон/
        ├── transcript.md    расшифровка по голосам
        ├── summary.md       итог
        ├── session.log      лог именно этой записи
        ├── audio.flac       звук записи, хранится 7 дней
        └── meta.json        название, длительность, статус
```

Ключи — в связке ключей macOS, остальные настройки — в настройках приложения.
Записи старше 30 дней удаляются при запуске.

## Если что-то не так

Сначала — «Проверить звук» в меню: он проверяет всю цепочку и называет проблему.

| Симптом | Причина и что делать |
|---|---|
| «Звук собеседника не пишется» | нет разрешения на запись звука системы: Системные настройки → Конфиденциальность и безопасность → Запись экрана и звука системы |
| Клавиша диктовки не работает, в меню ⚠️ | нет Универсального доступа. Если приложение в списке уже включено — это запись от старой сборки: удалите её кнопкой «−» и добавьте заново |
| Fn открывает эмодзи | Системные настройки → Клавиатура → для клавиши 🌐 «Ничего не делать» |
| Значок микрофона перечёркнут во время записи | микрофон выключен или выбран не тот вход |
| Запись идёт, а расшифровки нет | проверьте ключ AssemblyAI в настройках и лог |
| «Захват звука не запустился» | завис звуковой сервис macOS: `sudo killall coreaudiod` |
| Итога нет, расшифровка есть | проблема с ключом DeepSeek, текст цел и лежит в «Истории созвонов» |
| Расшифровка рваная, половина пропала | «История созвонов» → «Расшифровать заново»: запись уйдёт целиком, а не минутными кусками |

Нерасшифрованные куски приложение не выбрасывает: они сохраняются рядом с
записью файлами `нерасшифровано-NNN.flac`.

## Обновление с версии 1.x

- Ключи и ссылка на чат из старого `config.json` переезжают в связку ключей сами,
  при первом запуске. Записи и история остаются на месте
- ffmpeg, SwitchAudioSource и BlackHole больше не нужны, их можно удалить
- Разрешения на микрофон и звук системы нужно выдать заново: для macOS это
  новое приложение

## Приватность

Микрофон пишет всё, что слышит, включая посторонние разговоры рядом. Запись,
расшифровка и итог остаются на маке. Наружу уходят только звук — в выбранный
сервис распознавания, текст — в DeepSeek или OpenAI для итога и оформления,
и итог — в ваш Telegram-чат.
