# Live Transcriber

![версия](https://img.shields.io/badge/версия-1.0.0-blue) ![платформа](https://img.shields.io/badge/платформа-macOS%2013%2B-lightgrey)

Приложение в строке меню macOS: пишет созвон вместе со звуком собеседника,
расшифровывает речь, делает итог и присылает его в Telegram.

Работает целиком на вашем маке. Ключи хранятся локально, в репозиторий не попадают.

## Что умеет

- Запись микрофона и системного звука одновременно (собеседник тоже попадает в запись)
- Проверка звука до начала: видно, слышит ли микрофон и доходит ли звук собеседника
- Расшифровка с разделением по голосам — AssemblyAI
- Итог разговора — DeepSeek, промт можно менять перед каждой записью
- Итог в отдельном окне с кнопкой «Скопировать»
- Отправка итога в Telegram-чат или в тему группы
- История за 30 дней: итоги и полные расшифровки, всё старше удаляется само
- Подробный лог: и общий, и отдельный по каждой записи

## Установка

Нужен macOS 13 или новее.

```bash
brew install ffmpeg blackhole-2ch switchaudio-osx
```

BlackHole — виртуальное аудиоустройство, через него в запись попадает голос
собеседника. После установки перезайдите в систему.

### Запуск из исходников

```bash
git clone https://github.com/sashafyc/live-transcriber.git
cd live-transcriber
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python3 main.py
```

### Сборка приложения

```bash
.venv/bin/python3 scripts/build_app.py
```

Готовый `Live Transcriber.app` появится в `dist/`, скопируйте его в «Программы».
Чтобы запускался сам, добавьте его в «Объекты входа» в настройках системы.

## Ключи

При первом запуске приложение попросит ключи. Ввести их можно в любой момент:
значок в строке меню → «Настройки». Там же кнопка «Проверить ключи».

| Что | Где взять | Без него |
|---|---|---|
| Ключ AssemblyAI | [assemblyai.com](https://www.assemblyai.com) | записи не расшифровываются |
| Ключ DeepSeek | [platform.deepseek.com](https://platform.deepseek.com) | не будет итога, останется расшифровка |
| Токен Telegram-бота | [@BotFather](https://t.me/BotFather) | итог не уйдёт в чат |
| Ссылка на чат | скопировать ссылку на любое сообщение в чате | итог не уйдёт в чат |

Ссылка на чат понимается в любом виде: `https://t.me/c/1234567890/42`,
`-1001234567890/42`, `-1001234567890` или `@имяканала`. Если в ссылке есть номер
темы, итоги уйдут именно в неё. Бота нужно добавить в чат и дать право писать.

Ключи лежат в `~/Library/Application Support/Live Transcriber/config.json`
с правами только для владельца. В репозитории их нет и быть не может.

## Как пользоваться

1. Значок в строке меню → «Начать запись»
2. Впишите название и при желании поправьте задание для итога
3. Кнопка «Проверить звук» покажет, слышно ли микрофон и идёт ли звук собеседника
4. «Начать запись» — значок станет 🔴, а если звука нет, сменится на 🔇
5. «Остановить и получить итог» — приложение дорасшифрует хвост, сделает итог,
   покажет его и отправит в Telegram

Во время записи системный звук идёт через устройство LT-Auto: вы слышите всё как
обычно, и то же самое попадает в запись. После остановки прежний выход звука
возвращается сам.

## Где что лежит

```
~/Library/Application Support/Live Transcriber/
├── config.json              ключи и настройки
├── logs/app.log             общий лог с ротацией
└── records/
    └── 2026-09-18-1610-созвон/
        ├── transcript.md    расшифровка по голосам
        ├── summary.md       итог
        ├── session.log      лог именно этой записи
        └── meta.json        название, длительность, статус
```

Всё старше 30 дней удаляется при запуске. Срок меняется в `config.json`
полем `retention_days`.

## Если что-то не так

Сначала — «Проверить звук» в меню, он проверяет всю цепочку и называет проблему.

| Симптом | Причина и что делать |
|---|---|
| «Звук собеседника не пишется» | не установлен BlackHole либо не создаётся LT-Auto: `brew install blackhole-2ch` и перезайти в систему |
| Значок 🔇 во время записи | микрофон выключен или выбран не тот вход |
| Запись идёт, а расшифровки нет | проверьте ключ AssemblyAI в настройках и лог |
| ffmpeg не отдаёт звук совсем | завис звуковой сервис macOS: `sudo killall coreaudiod` |
| Итога нет, расшифровка есть | проблема с ключом DeepSeek, текст цел и лежит в истории |

Не расшифрованные куски приложение не выбрасывает: они сохраняются рядом с
записью файлами `нерасшифровано-NNN.mp3`.

Общий лог: `~/Library/Application Support/Live Transcriber/logs/app.log`

## Приватность

Микрофон пишет всё, что слышит, включая посторонние разговоры рядом. Запись,
расшифровка и итог остаются на маке, наружу уходят только аудио в AssemblyAI,
текст в DeepSeek и итог в ваш Telegram-чат.
