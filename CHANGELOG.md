# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
нумерация — [семантическая](https://semver.org/lang/ru/).

## [1.0.2] — 2026-09-18

### Исправлено
- Окно записи, отчёт о звуке и сообщения стали обычными окнами: приложение не замирает, даже если окно осталось открытым или ушло за другие

## [1.0.1] — 2026-09-18

### Исправлено
- Окно итога больше не подвешивает приложение: оно стало обычным, а не модальным
- В окнах приложения разметка показывается как разметка: жирный виден жирным, таблицы разворачиваются в строки
- Значок в строке меню гаснет после остановки записи, а не остаётся красным

## [1.0.0] — 2026-09-18

Первая версия. Отдельное приложение вместо связки «скрипт на маке плюс сервер»:
запись, расшифровка и итог делаются локально, сервер больше не нужен.

### Добавлено
- Запись микрофона и системного звука одновременно через устройство LT-Auto
- Проверка звука до начала записи: инструменты, устройства, оба потока по отдельности
- Расшифровка с разделением по голосам через AssemblyAI, кусками по минуте
- Итог разговора через DeepSeek, с заданием, которое можно менять перед записью
- Окно итога с кнопками «Скопировать» и «Отправить в Telegram»
- Отправка итога в чат или тему Telegram, длинные итоги режутся по абзацам
- История за 30 дней с итогами и расшифровками, старое удаляется само
- Настройки с полями для четырёх ключей и проверкой каждого
- Лог приложения с ротацией плюс отдельный лог каждой записи
- Предупреждение, если две минуты подряд в записи тишина

### Исправлено по следам старого приложения
- Multi-output создавался пустым: ключ списка подустройств должен быть
  `subdevices`, а не `sub`. Из-за этого на macOS 27 звук собеседника не писался
- Имена устройств с кириллицей роняли запуск записи: в бандле локаль ASCII,
  поэтому `subprocess` везде работает с байтами и явным utf-8
- Минута записи весила почти два мегабайта и не проходила по медленному каналу —
  теперь кусок сжимается в mp3 и весит вчетверо меньше
- Сетевая ошибка больше не теряет кусок записи: три попытки, а затем аудио
  сохраняется рядом с записью
- Иконка приложения не рисовалась, потому что была ссылкой на файл в защищённой
  папке — теперь она лежит внутри бандла
