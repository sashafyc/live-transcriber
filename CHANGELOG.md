# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
нумерация — [семантическая](https://semver.org/lang/ru/).

## [2.1.0] — 2026-10-28

### Добавлено
- Установка из образа `.dmg`: перетащить в Программы, и всё
- Окно первой настройки: разрешения и ключи по шагам, со ссылками, где их взять,
  и проверкой каждого ключа. Приложение само выбирает сервисы по введённым ключам
- Длинная диктовка распознаётся кусками по паузам, пока вы говорите: после
  отпускания клавиши ждать 1–2 секунды вместо 5–10
- Модель итога созвона на выбор (OpenAI или DeepSeek); если OpenAI не ответил,
  итог делает DeepSeek
- Подсказка под полем модели: чем она хороша, цена и скорость
- Модели DeepSeek V4.1 Flash и V4 Pro

### Изменено
- Настройки разделены на «Диктовку», «Созвоны», «Ключи» и «Основные» со списком слева
- Оформление больше не выполняет просьбы из диктовки, а оформляет их как текст;
  если модель переписала текст, вставляется распознанный как есть
- `deepseek-chat` в настройках сам заменяется на `deepseek-flash`

## [2.0.0] — 2026-10-28

Приложение переписано на Swift: одно нативное приложение вместо Python-скрипта
и отдельной программы для диктовки.

### Добавлено
- Диктовка: держите Fn (или правый Option, Command, Control), отпустили — текст
  вставляется туда, где курсор. Плашка с волной внизу экрана, история за сутки
- Распознавание диктовки через OpenAI, AssemblyAI или свой OpenAI-совместимый адрес,
  модель вписывается вручную
- Оформление диктовки нейросетью (OpenAI или DeepSeek): абзацы, пунктуация, без
  слов-паразитов; исходник остаётся в истории
- Для созвонов отдельный выбор сервиса и модели распознавания
- Задание для итога по умолчанию меняется в настройках

### Изменено
- Звук пишется средствами macOS, без ffmpeg: микрофон и звук собеседника идут двумя
  дорожками, сведёнными по часам системы, — начало созвона больше не теряется,
  даже если собеседник заговорил не сразу
- Ключи хранятся в связке ключей macOS; ключи версии 1.x переезжают туда сами
- Минимальная система — macOS 15, только Apple Silicon

### Удалено
- Зависимость от ffmpeg, SwitchAudioSource и BlackHole, запасной путь для macOS
  старее 14.4 с переключением выхода
- Python-версия и сборка через py2app

## [1.0.0] — 2026-09-18

Первая версия. Отдельное приложение вместо связки «скрипт на маке плюс сервер»:
запись, расшифровка и итог делаются локально, сервер больше не нужен.

### Добавлено
- Запись микрофона и системного звука одновременно через устройство LT-Auto
- Проверка звука до начала записи: инструменты, устройства, оба потока по отдельности
- Расшифровка с разделением по голосам через AssemblyAI, кусками по минуте
- Итог разговора через DeepSeek, с заданием, которое можно менять перед записью
- Окно итога с кнопками «Скопировать» и «Отправить в Telegram»
- Отправка итога в чат или тему Telegram, длинные итоги режутся по абзацам
- История за 30 дней с итогами и расшифровками, старое удаляется само
- Настройки с полями для четырёх ключей и проверкой каждого
- Лог приложения с ротацией плюс отдельный лог каждой записи
- Предупреждение, если две минуты подряд в записи тишина

### Исправлено по следам старого приложения
- Multi-output создавался пустым: ключ списка подустройств должен быть
  `subdevices`, а не `sub`. Из-за этого на macOS 27 звук собеседника не писался
- Имена устройств с кириллицей роняли запуск записи: в бандле локаль ASCII,
  поэтому `subprocess` везде работает с байтами и явным utf-8
- Минута записи весила почти два мегабайта и не проходила по медленному каналу —
  теперь кусок сжимается в mp3 и весит вчетверо меньше
- Сетевая ошибка больше не теряет кусок записи: три попытки, а затем аудио
  сохраняется рядом с записью
- Иконка приложения не рисовалась, потому что была ссылкой на файл в защищённой
  папке — теперь она лежит внутри бандла
